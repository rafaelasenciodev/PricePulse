# PricePulse

A price-tracking platform: monitor product prices, consult price history, and get alerted when a product reaches a target price.

> **Status: pre-implementation.** The domain is being defined before any code is written. See [`docs/`](docs/README.md).

PricePulse is simultaneously a Master's Final Project (TFM), a professional portfolio project, and a vehicle for a repeatable, design-first engineering methodology (see [`docs/features/README.md`](docs/features/README.md)).

## Data honesty

The planned initial implementation uses a **simulated price provider**. No real retailer data is planned for it, and the project does not scrape retailers. Real providers could be added later behind an adapter, subject to their licence terms.
